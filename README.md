# LocationLab 2.0

LocationLab 2.0 — GPS mock Android, tema nero, nessuna pubblicità. Funzioni: percorso geografico diretto partenza-arrivo con velocità impostabile (non navigazione stradale), altitudine/precisione, oscillazione GPS, pausa/riprendi/termina dalla notifica, ultima posizione ripristinata senza autoavvio, km/h-mph e metri-piedi, preferiti con nome categoria note e backup JSON compatibile con la 1.0. APK: Actions > LocationLab Android APK > artefatto LocationLab-2.0-APK. I sorgenti completi sono in LocationLab-source.tar.xz, estratti dal workflow. Prima di disinstallare vecchie versioni salvare i preferiti; la firma debug potrebbe cambiare.
